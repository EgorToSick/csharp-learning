# Четыре задачи на двумерные массивы в C#
Задачу 1 придумал сам, остальные задачи сгенерированы нейросетью DeepSeek. Все задачи выполнены в одном скрипте.
## Задача 1. Заполнение двумерного массива
Создаётся двумерный массив размера NxN (N определяет пользователь), после чего в цикле по i и вложенному j ввод пользователя (если верный) помещается в соответствующую [i,j] ячейку массива. После этого массив выводится на экран.
## Задача 2. Сложение элементов по строкам и столбцам
Два одномерных массива sunX и sumY отвечают за суммы элементов в строках и столбцах соответственно. Пробегая по двумерному массиву через i и j, производятся операции сложения. sumX[i] складывает элементы строки, sumY[j] складывает элементы столбца.
## Задача 3. Максимум и минимум с индексами
Необходимо вывести максимальные и минимальные числа двумерного массива с их индексами. Если чисел несколько, вывести все вхождения. Методом "пузырька" определил максимальное и минимальное число, после чего в новом пробеге по массиву вывожу вхождения максимального и минимального чисел.
## Задача 4. Транспонирование без создания второго массива
Необходимо транспонировать двумерную квадратный массив, не создавая второй. В пробеге по массиву менял местами элементы [i,j] и [j,i] при условии (i < j). После этого - вывод получившегося массива.
