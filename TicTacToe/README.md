# "Крестики-нолики" в консольной программе с конечным автоматом и процедурной реализацией.
## Программа состоит из:
- Главное меню
- Игровой раунд
- Информация о правилах игры
Каждое из этого является состоянием конечного автомата.
## Главное меню
Реализовано с помощью конструкции операторов switch и case. Выбор в меню = изменение состояния конечного автомата (Выход - завершение цикла программы).
## Игровой раунд
Игровое поле является двумерным массивом размера 3х3, изначально заполненым элементами типа данных char со значением '.' - это необходимо для определения свободных клеток поля. При выводе на экран незаполненные клетки выводятся с соответствующей этой клетке цифрой по формуле i*3+j+1.\
Ход крестиков или ноликов определяется булевой переменной. При каждом ходе переменная меняет своё значение на противоположное.\
Неправильный ввод обрабатывается с комментариями и ожиданием ввода пользователя.
## Итог
Код - читаемый. Программа - полноценная. Для пользователя - удобно. Следующие шаги - реализация этой игры с подходом ООП, а после - осуществление работы программы как десктопного приложения с графическим интерфейсом с помощью технологии WPF.
