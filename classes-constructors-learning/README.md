# Перегрузка конструкторов в классах C#
## Класс - обыкновенная дробь
## Функциональность
Вы можете создать обыкновенную дробь в формате "числитель/знаменатель". 
Возможные действия: сложение, вычитание, умножение, деление, сокращение 
(выполняется автоматически после каждого действия), преобразование в строку. 
Каждое из этих действий возвращает новую дробь.
## Перегрузка конструкторов
Цель выполнения работы - изучение перегрузки конструкторов.\
В этом классе предусмотрены три варианта инициализации: только числитель (целое число, знаменатель равен 1), числитель и 
знаменатель, другая дробь в аргументе (копирование дроби).
